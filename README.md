# Tiago Vindima Selection

Site imobiliário da Tiago Vindima Selection.

## Stack

- [Next.js 15](https://nextjs.org/)
- [React 18](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- Deploy: [Vercel](https://vercel.com/)

## Como executar

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) no browser para ver o resultado.

## Deploy

O site é publicado automaticamente no Vercel em [tiagovindima-com-selection.vercel.app](https://tiagovindima-com-selection.vercel.app).
